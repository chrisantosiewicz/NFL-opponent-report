Bears Opponent Tendency Report

Every Tuesday in the season, a pipeline pulls the latest NFL play-by-play, runs SQL models in DuckDB, tests the data, and publishes a one-page tendency report on the Chicago Bears' next opponent. Every tendency uses only games played before that week, and every number shows its sample size.
